# Cursor-inspired design reference

This project uses a calm, editorial style inspired by Cursor's public website. It is a design reference, not a requirement to copy Cursor branding or content.

## Visual direction

- Use a warm cream page background (`#f7f7f4`) rather than stark white.
- Use warm near-black text (`#26251e`) and body text (`#5a5852`).
- Use one accent colour, orange (`#f54e00`), sparingly for key calls to action and small identity details.
- Let whitespace and thin 1px dividers (`#e6e5e0`) create structure. Do not use drop shadows.
- Keep the mood quiet, readable, and magazine-like rather than loud or overly technical.

## Typography

- Prefer a system sans-serif or Inter. Do not rely on the proprietary CursorGothic font.
- Main body text: 16px or larger, normal weight, generous line height.
- Display headings: normal/medium weight with slight negative letter spacing; avoid very heavy bold headings.
- Use a monospace font only for actual code or technical content.

## Layout and components

- Keep content within a max width near 1200px.
- Use generous section spacing (about 80px on larger screens).
- Cards should be white on the cream canvas, with a 1px hairline border and a modest 12px radius.
- Buttons use an 8px radius. The primary button is orange with white text; secondary buttons are white with a thin border.
- Navigation is simple and approximately 64px high.

## Responsive behavior

- Below 640px, stack card grids into one column and reduce hero heading sizes.
- Keep interactive controls large enough for touch (at least 40px high).
- Avoid horizontal scrolling and preserve readable margins on narrow screens.

## Guardrails

- Do not use Cursor's name, logo, copyrighted visual assets, or proprietary font files as site branding.
- Keep orange as a scarce accent instead of using many competing colours.
- Use coloured status pills only when they convey a real status or category.
